# OFFSCRIPT implementation brief

Version 1.0. Documented, not independently reproduction-tested.

Build a fictional creative-studio portfolio named OFFSCRIPT. Its audience is design-conscious founders and creative collaborators. The core journey is to explore original concept artwork, inspect a project, and download a short personal creative brief as Markdown.

Use an overscale but short sans-serif headline, `Ideas, off script.`, followed by a broad photographic hero rather than a conventional split landing-page graphic. The signature material is translucent orange ribbed resin. Supporting works explore aluminum furniture and an orange glass gallery threshold. Keep one orange accent against cool gray, with a consistent system for automatic light/dark modes. Use DM Sans, square geometry, generous empty space, and restrained transitions. Do not add customer logos, business statistics, testimonials or stock availability claims.

Compose the remaining project images at unequal widths and vertical offsets, flattening to one column on mobile. Include project-detail dialogs with previous/next navigation and an accessible close action, a short studio statement, three service disclosures, and a brief form. The form asks for a project name, medium, idea, and feeling. Validate required fields and export a local Markdown file. Never show an email-sent or order-confirmed result.

Use original generated assets saved locally, semantic markup, keyboard focus indicators, reduced-motion handling and a theme switch. Reserve image dimensions. Keep the complete hero and primary navigation usable on mobile. Verify desktop and narrow layouts, dialog focus restoration, project navigation, form validation and actual downloaded content.
