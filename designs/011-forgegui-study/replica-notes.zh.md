# ForgeGUI 首页学习复刻

原站：https://forgegui.com/  
采样日期：2026-09-07。复刻对象为浏览器渲染的新首页，而非搜索引擎抓取到的旧版静态页面。

## 打开方式

在本目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4173/ 。无需安装依赖、无需构建。更换端口可用 `PORT=4180 npm start`。

- `?lang=zh`：原站在中文浏览器中的中英混合文案。
- `?lang=en`：英文文案。
- 不指定语言时跟随浏览器。

## 内容和文件

- `index.html`：完整首页，8 个区块、页头页尾、原始 SVG 图标、全部 FAQ 答案、3 组弹窗模板。
- `styles.css`：原站公开样式，保留字体、尺寸、间距、断点、玻璃质感、按钮和卡片效果。
- `fonts.css`、`fonts/`：本地字体。标题 Instrument Serif，界面 Inter Tight，强调字 Cal Sans。
- `app.js`：可阅读的原生 JavaScript，重建首页交互。
- `replica.css`：弹窗可滚动区域、演示反馈、减少动画支持等少量补充。
- `boot.css`：原站 Logo 敲击和闪光入场动画。
- `server.mjs`：只监听本机，支持视频 Range 请求的静态服务器。
- `asset-manifest.json`：25 个原站资源的下载状态及字节大小。

3 段视频、平台 Logo、工具图标、展示底图和 4 张目录图片均来自原站公开素材，保留原文件。没有重新绘制或用近似图片替代。Instrument Serif 正体和斜体从原站使用的 Google Fonts 字体族本地化。

首页静态内容无需 React 启动，不包含原站账户、生成、支付、统计或追踪代码。资源运行时均从本地加载。

## 交互范围

已实现：

- 5 组桌面导航下拉、菜单互斥、点击外部和 Escape 关闭。
- 手机汉堡菜单、单组展开、长菜单内部滚动。
- 菜单进出动画、卡片悬停、按钮高光与按下效果。
- Logo 无缝滚动和 3 段循环视频。
- 首屏箭头平滑定位到工具区。
- 注册、登录、找回密码弹窗及相互切换。
- 密码显隐、本地表单约束、确认密码检查、键盘焦点限制和关闭后焦点恢复。
- 7 个 FAQ 的原生展开、折叠与键盘操作。第 5 个默认展开，与原站相同。
- 浏览器减少动态效果偏好。

注册和登录提交只显示本地演示反馈，不保存或发送输入。Google 按钮不会发起 OAuth。跳往首页以外的业务页面显示范围提示，工具入口打开注册弹窗，Plans 菜单定位到首页方案区。原站没有绑定动作的主工具卡和目录 Learn More 保留其静态行为。Discord 外链保留。

## 验证结果

在实际浏览器中比较了 320×740、390×844、768×1024、1024×768、1440×1000 五组尺寸：

- 8 个主要区块的高度逐项一致，测得差值均为 0 CSS px。
- 主要标题的字体族、字号、行高和包围盒一致。
- 页面无横向滚动；320px 下卡片也没有超出屏幕。
- 菜单、弹窗、密码显隐、无后端提交、FAQ 鼠标及键盘操作通过检查。
- 减少动态效果下视频暂停、运行中的 CSS 动画数量为 0。
- 本地控制台未发现错误或警告。
- 原站素材下载全部成功；本地资源观测没有外部网络请求。

这些结果验证了布局与交互，不代表所有动画帧已做逐像素图像差分。循环视频和 Logo 的截图会因采样时刻不同而不同。

## 加载速度的实际边界

本次本机未限速样本：TTFB 约 21 ms、DOMContentLoaded 约 104 ms、load 约 175 ms、FCP 约 172 ms、CLS 0。引导 Logo 本身参与首屏绘制，默认约 550 ms 敲击动画加 300 ms 渐隐；FCP 数值不能等同于主内容完整显示时间。

原站本次跨网加载有明显波动，不能据此推导复刻版的线上加速倍数。这些是浏览器 Performance API 的本次采样，不是公网实用户指标或 Lighthouse 评分，也未验证移动设备真实网络下的 INP。

完整资源约 24 MB，其中目录原图占比很大。为保留素材一致性，没有转码压缩；下方两段视频在接近视口时加载，离开视口时暂停。上线后的响应时间仍取决于服务器、缓存、带宽和设备。

## 建议学习的一个点：用材质层级引导点击

最值得学的是它如何用同一套玻璃材质，把用户注意力导向主要按钮：

1. 游戏视频先交代使用场景，黑色渐变遮罩稳定文字的可读性。
2. 普通工具卡片采用低亮度玻璃，主要按钮使用更亮的蓝色和内高光。
3. 衬线大标题负责吸引注意，Inter Tight 正文负责传递信息；同一按钮材质贯穿导航、工具卡、方案和弹窗。

练习时先只做一个按钮：保留相同尺寸和文案，分别关闭渐变、内高光、外阴影，再逐层恢复。观察哪一层让按钮从“蓝色椭圆”变成“有体积、可点击的控件”。接着将同一组 CSS 变量应用到卡片，练习保持页面一致性。

可以从 `styles.css` 中搜索 `.fg-button`、`--fg-gradient`、`--fg-shadow`、`.fg-card-top-glow` 开始阅读。
